SELECTED WORK · 02

Pose Pro

처음 참가한 팀 해커톤에서 초보 팀원들과 완성해 낸 비대면 재활 동작 보조 서비스

TEAM HACKATHON · FRONTEND

아는 기술이 적어도
맡은 화면은 끝까지 완성했습니다

React도 협업용 Git도 익숙하지 않았던 첫 팀 프로젝트였습니다. 인공지능 전공 팀원들이 OpenPose로 재활 동작 판별을 구현했고, 저는 HTML·CSS·JavaScript로 서비스 화면을 만들었습니다. Flask 서버에서 웹캠과 분석 영상을 제공하고, 프론트 화면에 연결해 부위별 재활 흐름을 구성했습니다.

코드를 메신저로 주고받을 만큼 서툴렀지만 제한 시간 안에 동작하는 결과물을 만들었습니다. 다른 참가자들이 지식을 꺼내 문제를 해결하는 모습을 보며, 기술을 체계적으로 쌓아 맡은 일을 스스로 완수하는 개발자가 되겠다는 목표가 분명해졌습니다.

GROWTH LOG

만들 수 있는 범위를
한 단계씩 넓혔습니다

학습의 목표는 강의 수료가 아니라 다음 프로젝트에서 스스로 선택할 수 있는 기술을 늘리는 것이었습니다.

  1. 2022

    웹의 가장 작은 단위에서 시작

    HTML과 CSS로 화면을 만들고 JavaScript로 컴포넌트가 상호작용하는 흐름을 익혔습니다.

  2. 2023

    팀 프로젝트와 서버의 흐름을 경험

    공동해커톤에서 첫 협업을 마친 뒤 Express, MongoDB, 세션 인증과 업로드를 구현한 YouTube 클론으로 웹 전체의 요청 흐름을 학습했습니다.

  3. 2024–25

    React로 상태와 인터랙션을 구조화

    Trello와 Netflix 클론을 통해 상태 관리, 서버 데이터 조회, Framer Motion 기반 인터랙션과 컴포넌트 분리를 반복했습니다.

  4. 2025–26

    프론트엔드를 넘어 제품의 데이터 흐름으로

    Next.js와 React Router에서 SSR, hydration, 캐시, SEO를 학습하고 Prisma·Drizzle·PostgreSQL·Supabase를 연결했습니다.

  5. NOW

    AI와 함께 일하는 방식을 설계 중

    Markdown 규칙과 프로젝트 문맥을 통해 AI의 작업 범위를 관리하고, 생성된 코드를 이해·검증하는 AX 역량을 쌓고 있습니다.
